prefix_key is generated automatically (10 characters). With a URL, nginx picks up the backend within a few seconds (/t/<prefix_key>/… → URL). Editing, deactivating or deleting a backend updates nginx automatically too. backend_id is the backend's BACKEND_ID setting: the sync refuses a backend whose /internal/info reports another id (protection against a wrong URL), and Entra sync authentication needs it for the token audience.

Nginx status

The map is rewritten from the registry right after a backend is created, edited or deleted, by the write_nginx_map job ("Jobs" tab) and by Reload. nginx tests the configuration (nginx -t) and reloads when the map changes.

    Conflicts

    A key claimed by more than one active backend is a conflict: the routing API answers 409 for it, so the user or agent is never sent to the wrong department. Fix the assignment on the backends; the sync removes the conflict.
